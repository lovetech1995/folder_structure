## [2026-03-27] Fix Bug Law Management

### Lessons Learned:
1. **Firestore Timestamp handling**: Always use `.toDate()` when passing Firestore Timestamps to `moment()` to avoid "Invalid date".
   - *Example*: `{text?.toDate ? text.toDate() : text}`.
2. **Shared State between Components**: Local hook state (`useState`) inside a custom hook like `useAction[Domain]` is NOT shared if the hook is called in separate components (e.g., `LawTable` and `DialogLawEdit`).
   - *Issue*: `LawTable` sets `fileList`, but `DialogLawEdit` sees its own default `[]`.
   - *Solution*: Move shared state (like `fileList` for multi-stage processes) to **Redux** (`reducer` and `action`) as per the "hạn chế dùng state" principle.

- Updated `law.type.js`, `law.reducer.js`, `law.selector.js`, `law.action.js` to support shared `lawFileList`.
